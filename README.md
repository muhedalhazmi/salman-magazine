# مجلة التوجيه الطلابي بمدرسة سلمان الفارسي الابتدائية

مجلة إلكترونية توعوية لمدرسة سلمان الفارسي الابتدائية، إدارة التعليم بمحافظة جدة.

## النشر

الموقع صفحات HTML ثابتة، وتُنشر الملفات من جذر المستودع عبر GitHub Pages عند كل تحديث لفرع `main`.

الرابط المنشور: https://muhedalhazmi.github.io/salman-magazine/

الصفحة الرئيسية: `index.html`.

## المحتوى

- `index.html`: المجلة وأقسامها وروابط الموارد المدرسية.
- `book-care.html` و`space-week.html`: صفحات البرامج.
- `assets/`: الصور والعروض والملفات المرتبطة بالمجلة.
